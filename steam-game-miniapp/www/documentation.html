Steam Game (Mini App)

A per-game quick-launch tile for the "Steam Machine (System Bridge)" parent driver. Selecting it in a room's Watch list launches the configured game on the Steam Machine via its steam:// URI; remote control is passed through to the Steam Machine driver.

Setup

  1. Add this driver to the project (one copy per game).
  2. Set Game Name (shown to users) and Steam App ID or URI - either the numeric App ID from steamdb.info (e.g. 620 for Portal 2) or a full URI such as steam://rungameid/620. The computed Launch URI property shows what will be sent.
  3. In Connections, bind this driver's "Steam Game" output to a free "Game App N" input on the Steam Machine driver.
  4. Verify the room has a valid audio path for this device (required for remote passthrough), then Refresh Navigators.

Custom icons (recommended)

To show game art in Navigators, make a copy of the .c4z per game: rename the file (e.g. steam-game-portal2.c4z), replace the images under www/icons/device/experience_*.png (70/90/300/512/1024 px), update the <name>/<model> and the five controller://driver/steam-game-miniapp/... icon URLs in driver.xml to the new file name, and bump <version>. Each renamed copy installs as its own driver.
