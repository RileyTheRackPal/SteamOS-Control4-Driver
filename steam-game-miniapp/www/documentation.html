Steam Game (Mini App)

A per-game quick-launch tile for the "Steam Machine (System Bridge)" parent driver. Selecting it in a room's Watch list launches the configured game on the Steam Machine via its steam:// URI; remote control is passed through to the Steam Machine driver.

Setup

  1. Add this driver to the project (one copy per game).
  2. Set Game Name (shown to users) and Steam App ID or URI - either the numeric App ID from steamdb.info (e.g. 620 for Portal 2) or a full URI such as steam://rungameid/620. The computed Launch URI property shows what will be sent.
  3. In Connections, bind this driver's "Steam Game" output to a free "Game App N" input on the Steam Machine driver.
  4. Verify the room has a valid audio path for this device (required for remote passthrough), then Refresh Navigators.

Box art in Navigators (recommended)

Control4 Navigator tile icons are static and bound to the driver type, so real per-game box art means one driver per game with the art baked in. Rather than hand-edit icons, use the generator - it fetches the game's box art from Steam by App ID and builds a ready per-game driver:

pwsh tools/make-game-driver.ps1 -AppId 620            # Portal 2, art auto-fetched
pwsh tools/make-game-driver.ps1 -AppId 292030 -Name "The Witcher 3" -Fit pad

This outputs dist/steam-game-<appid>.c4z with the box art as the Navigator icons and the App ID + name pre-filled, so on add it works with no further configuration - just bind its "Steam Game" connection to a free Game App slot on the Steam Machine driver. -Fit crop (default) fills the square tile; -Fit pad shows the whole capsule letterboxed. Art comes from Steam's public CDN (falls back through capsule/header if a game has no portrait art).

This blank template driver still works as-is (enter the App ID by hand); it just shows a generic icon instead of box art.
